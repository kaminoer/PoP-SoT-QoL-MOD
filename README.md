# Prince of Persia: The Sands of Time Quality-of-Life mod

This mod lets you disable post-processing effects in SoT. In the future, it will also support controllers (in-menu navigation) and full dialog/cinematics subtitles.

# Features
- Fog and blur disabled by default.
    - Press F11 to toggle fog. Press F12 to toggle blur.
- Blur is heavily used to render time power effects. This mod checks if time powers are active and temporarily restores blur for their duration. Otherwise you'd get a black screen when rewinding or slowing down time.

# Installation
Download [d3d9.dll](https://github.com/kaminoer/PoP-SoT-QoL-MOD/releases/download/v1.0/d3d9.dll) and place it in your game folder, next to POP.exe.
